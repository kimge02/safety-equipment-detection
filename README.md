# YOLOv11 기반 안전장비(안전모/조끼) 탐지 — 그리드 실험 재현

3학년 1학기 도전학기제 프로그램에서 팀 프로젝트로 진행했던 YOLOv11 기반
안전장비 탐지 논문의 실험을 재현했다. 원본 코드는 팀 갈등으로 분실되어,
논문에 기술된 스펙(모델/배치/학습률)을 기준으로 처음부터 다시 구현하고
그리드 서치로 전체 조합을 재현·비교했다.

## 데이터셋

Kaggle "Safety Helmet and Reflective Jacket" (niravnaik)
- 학습 1,575장, 테스트 1,575장
- 클래스: Safety-Helmet, Reflective-Jacket

## 실험 설계

논문에서 비교한 것과 동일하게, 모델 크기(n/s) × batch(16/32/64, s는 16/32) ×
learning rate(0.001/0.01) 조합 총 10개를 전부 학습해 비교했다.

## 논문 대비 비교

| | 논문 (n, batch16, lr0.001) | 재현 |
|---|---|---|
| mAP (표기: 0.5~0.95) | 0.968 | 0.9599 (mAP50 기준) |

논문의 mAP50-95 실측값(재현 결과 0.7757)과 논문 표기값(0.968)의 격차가 커서,
논문 표에 기재된 수치는 mAP50-95가 아니라 mAP50을 지칭한 것으로 추정된다.
mAP50 기준으로는 논문값(0.968)과 재현값(0.9599)의 차이가 1%p 이내로 근접한다.

## 발견한 패턴

1. **Learning rate(0.001 vs 0.01)는 모든 조합에서 결과에 영향을 주지 않았다.**
   n/s 모델, 모든 batch 크기에서 동일한 lr 그룹끼리 결과가 소수점까지 일치했다.
   이는 원본 논문에서도 일부 조합(YOLOv11-s, batch16/32)에서 동일하게 관찰된
   현상으로, 재현을 통해 다시 확인했다.
2. **Batch 크기는 모델 크기별로 다른 영향을 보였다.** n모델은 batch64에서,
   s모델은 batch32에서 최고 성능이 나왔다 - 단순히 batch를 키운다고 항상
   좋아지는 게 아니라는 걸 보여준다.
3. **s모델이 n모델보다 전반적으로 근소하게 우수**했으나, 학습 시간은
   1.6~1.8배 더 걸렸다 - 정확도 개선 폭 대비 비용 증가가 크므로, 실시간
   추론이 중요한 엣지 배포 환경에서는 n모델(batch64)이 더 합리적인 선택일
   수 있다.

## 파일 구조

```
scripts/
├── train_one.py          # 단일 조합 학습 스크립트 (grid_results.csv에 자동 기록)
```

## 실행 방법

```bash
pip install ultralytics

# 예: n모델, batch16, lr0.001 조합 학습
python3 scripts/train_one.py n 16 0.001
```

## 한계 및 향후 계획

- 원본 팀 프로젝트 코드는 복구하지 못해 완전히 새로 구현했다. 데이터 전처리
  방식(augmentation 등) 세부사항까지 논문과 100% 동일하다고 보장할 수는 없다.
- ONNX 변환 및 실제 엣지 보드(Jetson/Raspberry Pi 등) 배포 벤치마크는 아직
  진행하지 않았다.
